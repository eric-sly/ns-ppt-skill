# NS-PPT Skill 使用说明

将 Nature / Science 当期目录制作成中英双语周报 PPTX/PDF。源页面可以由你在浏览器里保存，也可以让 agent 用内置脚本自动抓取；其余工作（解析、逐条翻译、排版、检查、导出）全部由 agent 完成，不需要额外的翻译服务或翻译 API。

## 准备工作

**环境（仅首次使用需要）**：Python 3.10+，并安装 beautifulsoup4、lxml、Pillow。

**源文件**：两种方式任选，产物都是 MHTML，后续流程完全一致。

- **让 agent 抓取（省事）**：agent 运行 `scripts/capture_issue.py`，用本机 Chrome/Edge 打开当期页面、展开封面描述、滚动完整期，再保存为 MHTML。需要先 `pip install playwright`，不需要额外下载浏览器。**抓不到的情况**（站点人机验证、页面条目明显偏少、找不到 digest 链接）脚本会以退出码 3 结束、把可疑页面移到 `rejected/`，并给出 `message_for_user`——agent 会照它提示你自己保存，不会拿坏页面凑数。
- **自己保存（可控）**：用浏览器打开当期页面，手动保存为「网页，单个文件 (*.mhtml)」。

| 期刊 | 需要的文件 |
|---|---|
| Nature | 当期目录页 1 个（展开封面描述至显示 `show less`，滚动完整期后保存） |
| Science | 3 个：当期目录页（展开描述至显示 `View Less`）、`In Science Journals` 详情页、`In Other Journals` 详情页 |

## 安装

把本仓库链接发给你的 agent，让它帮你安装即可——仓库里的 `skill/` 目录就是技能本体，复制到你所用客户端的 skills 目录（不同客户端路径不同，你的 agent 知道自己的路径）。

## 使用步骤

1. 告诉 agent 要做 Nature 还是 Science 周报。
2. 源文件二选一：让 agent 直接抓取当期（推荐，先确认当期已经上线）；或按上表自己保存好 MHTML，把路径发给 agent。
3. agent 完成逐条完整翻译、构建 PPTX 并导出 PDF。
4. 从输出目录取走成品（PPTX 与 PDF）。

## 质量控制

- 构建后自动运行内置结构审计；发现错误时命令会返回非零状态，但已生成的 PPTX 会保留，供 agent 检查和修正。
- 如果当前环境可用，构建器还会调用 `officecli` 做辅助检查；未安装或报告问题不会自动判定成品不可用。
- 自动检查用于发现明显的缺项、链接或格式问题，不能替代内容判断。agent 应报告检查结果，最终由使用者审核成品。
